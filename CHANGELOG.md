# Changelog

## 0.3.0

### Changes
- Updated interface to an analytical dark layout with network topology and timeline scrubber.
- Replaced text-based alert/status characters with semantic inline SVG icons.
- Streamlined typography and UI copy across all simulation controls, telemetry ribbons, and scenario tables.
- Removed legacy unused components and templates.

### Verification
- TypeScript build and ESLint checks pass without warnings.

## 0.2.0

### Changes
- Added policy preset profiles: balanced, free-trade, protectionist, austerity, stimulus, and crisis.
- Added browser storage persistence and JSON scenario import/export.
- Added policy diagnostic insights analyzing debt, inflation, trade dependency, and stress states.

## 0.1.0

### Initial Release
- Multi-country economy simulation engine with production, consumption, and trade routing.
- Scenario A/B comparison workflow.
- Seeded pseudo-random event generator for economic shocks.
- Chart.js time series visualizations and summary metrics.
